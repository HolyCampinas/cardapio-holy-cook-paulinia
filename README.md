# Cardápio Holy Cook Paulínia

Versão online do cardápio da loja — o mesmo PDF que o agente de WhatsApp envia, agora como página
web para mandar por link.

**No ar:** https://holycampinas.github.io/cardapio-holy-cook-paulinia/

- `index.html` — a página inteira (HTML + CSS + JS, sem dependências)
- `img/` — fotos extraídas do PDF oficial `cardapio-produtos-paulinia.pdf`

Para atualizar preço ou produto, edite `index.html` e faça commit — o GitHub Pages publica sozinho.
